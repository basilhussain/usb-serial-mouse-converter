This folder contains the design files for PCB schematic and layout, as well as 3D model for mounting bracket.

Gerber files for PCB manufacturing and 3D STEP file for sheet-metal mounting bracket can all be found in the 'Releases' section of the GitHub repository.

Schematic and PCB layout were created with [DipTrace](https://diptrace.com) version 5.x.

Mounting bracket 3D model was created in [FreeCAD](https://www.freecad.org) version 1.x.

* 1.6 mm thickness
* 2 layers
* 1 oz / 35 µm copper

* Stainless steel
* 1 mm thickness
* One 90° bend operation
